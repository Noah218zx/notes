# 数据泄露（data leakage）
## 概念
数据泄漏（data leakage）指的是机器学习模型的创建者犯的一个错误，他们意外地在测试集和训练集之间共享了信息。通常，在将数据集拆分为测试集和训练集时，目标是确保两者之间没有共享数据。这是因为测试集的目的是模拟真实世界中未见过的数据。
一个非常常见的错误是在机器学习的**数据预处理步骤**中泄漏信息，这些处理步骤即使也要应用于测试集，但它们也应该只拥有训练集的知识。
例如，如果你决定将PCA作为预处理步骤，你应该只在训练集上拟合你的PCA模型。然后，要将其应用于测试集，你只需在测试集上调用它的`transform`方法（对于`scikit-learn`模型而言）。相反，如果你在整个数据集上拟合你的预处理器，你就会从测试集泄漏信息，因为预处理模型的参数将是在拥有测试集知识的情况下被拟合的。
