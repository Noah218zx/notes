# 概念
输入一个测试样本，模型将通过查看模型的特征来做出分类决策，决策树的目标是从多数决策树模型中，尝试挑选一个在训练集上表现良好，并且理想状态下也能泛化新数据的树
![[Pasted image 20251201144318.png]]
最顶上的点叫做root node（根节点），其他节点叫做decision node（决策节点），底部的节点叫做leaf node(叶节点)
# 训练过程
1. 决定根节点
2. 先专注左节点用什么特征
3. 最后创建叶节点，决定叶节点的结果（是或否）
## 如何决定每个节点的特征进行分裂
可以通过检测不同标签分类后子集中的纯度（purity），纯度越高， 模型越好
## 决定什么时候停止分裂
1. 可以选择在纯度达到100%时停止分裂
2. 可以选择在树达到最大深度（maximum depth）时停止分裂，最大深度可以自己决定  %%深度是指从根节点到达该节点所需要的跳数 %%
3. 当纯度低于某个值时停止分裂，这样可以有效降低过拟合
4. 当一个节点中的例子数量低于某个值时停止分裂
# 测量纯度（inpurity）
## 熵（entropy）
可以用H（x）来表示熵，熵可以用来表示样本的不纯度，当样本集为1:1时，不纯度最大，熵值为1。若全为猫或全为狗，熵值为0，此时不纯度也最小

# 选择分割：信息增益（information gain）
可以通过计算不同特征分割下的不纯度来决定哪个更合适。
1. 首先算出每个分支的**不纯度（inpurity）**，
2. 再算出各个分支不纯度的**加权平均数（weighted average）**，
3. 最后用根节点的熵减去这个加权平均数得到**信息增益（information gain）**，信息增益越大越好
