# 数据划分（data splitting）
## 概念
将数据划分为几个部分，主要是为了检验训练的算法是否能真正预测数据，还是只是记住了训练集的数据
## 训练集、验证集和测试集

数据划分通常取决于具体用例，但通常我们将数据分为三个主要数据集：

- 训练集（training datasets）：用于拟合模型的数据样本，这是我们实际用来训练模型的数据集（在神经网络的情况下是权重和偏置）。模型会看到这些数据并从中学习。
- 验证集（validation datasets）：用于在调整模型超参数时，对在训练集上拟合的模型提供无偏评估的数据样本。随着验证集上的技能被纳入模型配置，评估会变得更加有偏。
- 测试集（test datasets）：用于提供对在训练数据上拟合的最终模型的无偏评估的数据样本。![[Pasted image 20251117141605.png]]

## 交叉验证（cross-validation）

当没有足够的数据来训练模型时，移除一部分数据进行验证会导致欠拟合的问题。通过减少训练数据，我们可能会丢失数据集中的重要模式/趋势，这反过来又增加了由偏差引起的误差。因此，我们需要一种方法，既能提供足够的数据来训练模型，又能留下足够的数据进行验证。交叉验证正是这样做的。
### K折交叉验证（k-fold cross validation）

在K折交叉验证中，数据被分成k个子集。现在，保留方法重复k次，每次k个子集中的一个子集用作测试集/验证集，其他k-1个子集放在一起形成训练集进行训练。误差在所有k次试验中平均值，以获得模型的总有效性。
这样一来，每个数据点恰好有一次在验证集中，有k-1次在训练集中。因为我们使用了大部分数据进行拟合，这显著减少了偏差，因为大部分数据也被用于验证集，同时也显著减少了方差。交换训练集和测试集也增加了这种方法的有效性。作为一般规则和经验证据，通常首选K=5或10，但没有固定值，它可以取任何值。![[Pasted image 20251117142221.jpg]]
###  分层K折交叉验证（stratified k-fold cross validation）
在某些情况下，响应变量可能存在很大的不平衡。例如，在关于房价的数据集中，可能有大量高价房屋。或者在分类情况下，负样本可能是正样本的几倍。对于这类问题，对K折交叉验证技术进行了轻微修改，使每个折大概包含相同百分比的每个目标类别的样本
### 留P法交叉验证(leave-p-out cross validation)

这种方法从训练数据中留下p个数据点，即如果原始样本中有n个数据点，那么用n-p个样本来训练模型，p个点用作验证集。这对原始样本可以这种方式分离的所有组合重复进行，然后对所有试验的误差进行平均，以给出总体有效性。
但这种方法是穷举的，会对所有的可能组合训练和验证模型，会大大增加运算量

## sklearn的分割语法
``` python

from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X,                    # 特征数据
    y,                    # 目标数据
    test_size=0.2,        # 测试集比例，默认0.25
    train_size=None,      # 训练集比例，默认1-test_size
    random_state=None,    # 随机种子，用于复现结果
    shuffle=True,         # 是否在划分前打乱数据
    stratify=None         # 是否分层抽样
)

```
