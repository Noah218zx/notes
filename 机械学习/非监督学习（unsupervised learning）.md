# 聚类（Clustering）
算法会查看一组数据点，并自动找出相互关联或相似的点。
数据集中只有x，没有目标标签y
应用： 新闻文章分类，分析DNA数据，天文数据分析。
## k均值算法（k means）
1. 随机猜测符合要求的k个聚类的中心位置（cluster centroids）
2. 接着遍历每个点，看点更接近哪一个中心位置，并根据更接近哪个**聚类中心（cluster centroids）** 来分配这些点![[Pasted image 20251208142507.png]]
3. 之后再取一个聚类的点的平均位置作为下一个聚类中心的位置![[Pasted image 20251208142522.png]]
4. 之后再次查看样本点更接近哪个聚类中心，并进行分类
5. 之后重复以上步骤，直到聚类中心的位置不再变化![[Pasted image 20251208142823.png]]

### L2范数（L2 norm）
![[Pasted image 20251208143308.png]]
即$x_i$到最近聚类中心的距离，之后把这个点的值根据聚类中心的分类设定为$c^i$，如果一个聚类中心没有分配到任何点，则最好清除这个聚类中心或重新初始化这个点

---

## Distortion function(失真函数)（cost function）
- $c^{(i)}$= 样本 $x^{(i)}$ 当前被分配到的聚类（聚类编号为 1, 2, ..., K）的索引
- $u_k$ = 第 k 个聚类的中心
- $u_{c^{(i)}}$ = 样本 $x^{(i)}$ 所分配到的那个聚类对应的聚类中心

## 如何选择初始聚类中心
1. 多次不同地随机选择聚类中心
2. 选k个训练点作为初始聚类中心（更常用）

## 选择聚类数量
1. 根据聚类在后续的作用来决定聚类的数量
2. 通过elbow图来选择，一般选择图的拐点处
## 轮廓图（silhouette plot）
**轮廓图（silhouette plot）** 是评估聚类质量的重要工具，让我详细解释一下：

1. **轮廓系数（silhouette score）** 的含义：

- 每个数据点都有一个轮廓系数（silhouette score），范围在[-1, 1]之间
- 值越接近1，表示该点与其所属聚类匹配得越好
- 值接近0，表示该点可能位于两个聚类的边界上
- 值为负数，表示该点可能被分到了错误的聚类

2. 轮廓系数的计算：

- a：点与同一聚类中其他点的平均距离（衡量内聚性）
- b：点与最近的其他聚类中所有点的平均距离（衡量分离性）
- 轮廓系数 = (b-a) / max(a,b)

3. 轮廓图的解读：

- 每个聚类显示为一个水平的条形图
- 条形的长度表示该聚类中点的轮廓系数
- 图中通常有一条垂直的虚线表示所有点的平均轮廓系数
- 理想情况下：
    - 所有聚类都有相似的宽度
    - 轮廓系数都接近1
    - 没有负值

4. 实际应用中的判断标准：

- 平均轮廓系数 > 0.5：聚类结构合理
- 0.25 < 平均轮廓系数 < 0.5：聚类结构一般
- 平均轮廓系数 < 0.25：聚类结构较差
