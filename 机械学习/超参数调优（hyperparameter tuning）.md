# 概念
机器学习模型由两种不同类型的参数组成：

- **超参数** = 是指用户在开始训练前可以任意设置的所有参数（例如：学习率（learning rate）、正则化参数(batch size)、小批量梯度下降中的批量大小...）。
    
- **模型参数** = 则是在模型训练过程中学习得到的（例如：线性回归、神经网络中的权重...）。![[Pasted image 20251120142751.png]]
# 网格搜索（grid search）
通过网格搜索（grid search），我们可以为每个超参数创建一组可能的值，然后在"网格"中将他们相互测试
- **穷举搜索**：网格搜索的本质是一种暴力穷举法。
- **构建网格**：首先，你需要为你想要调优的每个超参数指定一个候选值列表。例如，对于学习率，你可能会尝试 `[0.001, 0.01, 0.1]`；对于正则化参数λ，你可能会尝试 `[0.1, 1, 10]`。
- **组合与评估**：然后，网格搜索会自动生成所有可能的参数组合。在上面的例子中，就会有 3 (学习率) × 3 (λ) = 9 种组合。对于每一种组合，它都会训练一个模型，并使用某种评估标准（如交叉验证分数）来衡量其性能。
# 随机搜索（random search）
它通过在超参数的预设搜索空间内**随机采样若干组超参数**，用每组超参数训练模型后评估性能，最终选择最优性能对应的超参数组合。
- 无需遍历所有可能：与网格搜索（ exhaustive search ）的 “全遍历” 不同，它随机挑选超参数组合，不用覆盖整个搜索空间。
- 依赖概率抽样：采样次数越多，找到最优超参数的概率越高，但需平衡计算成本（次数过多会增加训练时间）。
- 搜索空间预设：需提前定义每个超参数的取值范围（如学习率 0.001-0.1、树模型深度 3-10），采样过程在该范围内进行。
- 优势：效率高于网格搜索，能以更少的计算资源找到接近最优的超参数，尤其适合超参数数量多、搜索空间大的场景。
- 通过`n_iter`参数指定一个固定的计算预算（即总共要训练多少个模型），然后随机搜索在这个预算内进行探索。
当搜索空间很大时，推荐使用随机搜索
# 缺失值填补（missing value imputation）
在处理缺失值时，应该思考以下几个问题：

我有缺失值吗？它们在数据中是如何表示的？我应该舍弃含有缺失值的样本吗？还是应该替换它们？如果替换，应该用什么值来替换？
## 1.删除
处理缺失值最简单的解决方案是删除行或整个列。并没有一个用于删除的最优阈值，但你可以使用50%作为一个示例值，并尝试删除缺失值比例高于此阈值的行和列
## 2. 数值型填补（numerical imputation）
与删除相比，填补是更可取的选择，因为它保留了数据规模。然而，用何种值来填补缺失值是一个重要的选择。

除非有针对缺失值的默认值，否则一种流行的填补方法是使用各列的**中位数**。因为列的**平均值**对异常值很敏感，而**中位数**在这方面则更为稳健。
## 3. 类别型填补（categorical imputation）
用列中**出现次数最多的值**来替换缺失值是处理类别型列的一个好选择。但是，如果你认为列中的值是均匀分布的，并且没有占主导地位的值，那么填补一个像"Other"这样的类别可能更明智，因为在这样的情况下，你的填补方法很可能等同于一次随机选择
# 缩放（scaling）
在大多数情况下，数据集的数值特征没有特定的范围，并且彼此之间不同。缩放解决了这个问题。经过缩放过程后，连续特征在范围上变得一致。
通常可将数据都缩放为标准正态函数
# 标签编码（label encoding）
这种编码可以将分类特征转换为数值特征，并且这种编码方式通常更适用于**有序的类别数据**，并且如果数据集中的**类别特征数量巨大**，你可能会经常使用标签编码。
# 独热编码（one-hot encoding）
根据数据的不同，标签编码会引入一个新问题。例如，我们将一组`性别`数据编码成了数值数据。这实际上是类别数据，行与行之间没有任何关系。

这里的问题是，由于同一列中有不同的数字，模型会误解数据，并错误地认为存在某种顺序或层次结构，0 < 1 < 2。但事实完全不是这样。为了克服这个问题，我们使用独热编码。

我们主要对**名义数据(nominal data)** 使用独热编码。

独热编码是机器学习中最常见的编码方法之一。该方法将一列中的值分散到多个标志列中，并为它们分配0或1。这些二进制值表达了分组和编码列之间的关系。

这种方法将算法难以理解的类别数据转换为数值格式，使你能够在不丢失任何信息的情况下对类别数据进行分组![[Pasted image 20251120151543.png]]
# 处理异常值（handling outliers）
数据异常值会破坏并误导训练过程，导致训练时间变长、模型准确性降低，并最终导致结果更差。

在提及一些处理异常值的技术之前，最好说明一下，检测异常值的最佳方法是**可视化地展示数据**。所有其他统计方法都有可能出错，而可视化异常值则可能提供一个高精度决策的机会。

处理异常值有很多不同的方法，以下是一些流行的技术：

- **单变量方法**：此方法查找在一个变量上具有极端值的数据点。
    
- **多变量方法**：这里我们寻找在所有变量上的异常组合。![[Pasted image 20251120152055.jpg]]
- 闵可夫斯基误差：此方法减少了潜在异常值在训练过程中的贡献。与单变量和多变量方法不同，它不检测和清除异常值。相反，它减少了异常值将对模型产生的影响。
-闵可夫斯基误差是一个损失指数，它比标准的均方误差对异常值更不敏感。均方误差将每个实例的误差平方，使得异常值对总误差的贡献过大。闵可夫斯基误差通过将每个实例的误差提升到小于2的数字（例如1.5）来解决这个问题。这减少了异常值对总误差的贡献。
# 分箱/分桶（binning/bucketing）
![[Pasted image 20251120152325.png]]
- **等间距边界分桶**：边界是固定的，并且包含相同的范围（例如，0-4度，5-9度，和10-14度）。一些桶可能包含许多点，而另一些桶可能很少或没有点。
    
- **分位数边界分桶**：每个桶具有相同数量的点。边界不是固定的，并且可能包含一个狭窄或宽泛的值范围。
# 对数变换（log transform）
对数据进行对数变换，有助于处理**偏斜数据**，变换后，分布更接近正态分布。还**减少了异常值的影响**，这归因于量级差异的归一化，模型变得更加鲁棒。
应用对数变换的数据必须只有**正值**，否则会报错。另外，还可以在变换前为数据加1。这样，就确保了变换的输出是正数。
